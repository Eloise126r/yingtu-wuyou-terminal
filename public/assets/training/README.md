# 体位教学插图说明

本目录的 11 张 PNG 用于“影途无忧”候检终端的体位学习页面。

## 语料来源

- `影像技术检查指南_DX_CT_MR.xlsx`
- 《数字X线摄影检查技术专家共识》（中华放射学杂志，2016）
- 《CT检查技术专家共识》（中华放射学杂志，2016）
- 《MRI检查技术专家共识》（中华放射学杂志，2016）

提供的 Excel 中“体位示意图”列和“体位示意图集”图像列均为空，项目中也未找到小程序原图，因此本目录图片均由内置图像生成工具创建。

## 统一生成提示约束

- 用途：医院候检终端的医学影像体位教学插图。
- 风格：专业、清晰、矢量感的临床教学插图；浅蓝与青色；浅色背景；横向构图。
- 人物：穿着完整、无可识别身份的中性成人教学模型。
- 设备：按对应课程展示 DR 探测器、CT 机架或 MRI 机架及线圈。
- 内容：严格展示 Excel 语料对应的站位、卧位、进床方向、手臂位置、头托或线圈位置。
- 禁止：图内文字、标签、品牌、标志、水印、裸露解剖、针具、诊断影像或令人不适的医疗情景。
- 安全边界：图片仅用于候检教学，实际摆位以现场技师指令为准。

## 文件映射

- `dr-chest-pa.png`：胸部 DR 后前位（PA）。
- `dr-chest-lateral.png`：胸部 DR 侧位。
- `dr-limb.png`：四肢 DR，手掌后前位示例。
- `ct-head.png`：颅脑 CT 平扫。
- `ct-chest.png`：胸部 CT 平扫。
- `ct-abdomen.png`：腹部 CT。
- `ct-abdomen-pelvis.png`：腹盆部 CT。
- `mri-head.png`：颅脑 MRI。
- `mri-spine.png`：脊柱 MRI。
- `mri-abdomen.png`：腹部 MRI。
- `mri-joint.png`：膝关节 MRI 示例。
