# 影途无忧

医学影像检查智能候诊与全流程引导终端。项目面向 21.5 英寸以上、1920×1080 横屏触摸终端，第二阶段在第一版视觉体系与首页结构上完成了候检全流程闭环。

本仓库仅包含终端网页，与“影途无忧”小程序保持为两个独立代码库。

在线演示：<https://eloise126r.github.io/yingtu-wuyou-terminal/>

## 运行

```bash
pnpm install
pnpm dev
```

生产构建与预览：

```bash
pnpm build
pnpm preview
```

## 第二阶段能力

- 公共候检屏仅展示票号、脱敏姓名与状态，不暴露检查项目或敏感病情。
- 五组可切换演示病例，共享签到、准备、安全问卷、体位学习、暂离、急诊插入、叫号与小程序同步状态。
- 覆盖 DR、CT 平扫、CT 增强、MRI 平扫、MRI 增强的结构化准备知识。
- 覆盖 MRI 植入物与 CT 增强风险问卷，命中风险时必须由工作人员二次确认。
- 11 个体位训练课、屏气训练，以及依据 DX/CT/MR 检查指南语料生成的统一标准风格体位插图。
- 60 条影像检查常见问题，按绿/黄/红三级风险输出安全边界。
- 12 秒无操作隐私倒计时、长辈模式、急诊优先与全屏叫号演示。

## 可直接演示的路径

- `/` 公共候检首页
- `/scan` 扫码签到
- `/patient` 患者候检总览
- `/preparation` 检查准备知识
- `/safety`、`/mr-safety` 安全筛查
- `/training` 体位与屏气训练
- `/preparation-summary` 准备完成汇总
- `/waiting` 候检、暂离与返回
- `/emergency` 急诊优先演示
- `/calling` 全屏叫号演示
- `/ai` 影像检查问答

## 验证

- `pnpm run build`：通过，执行 `tsc -b && vite build`。
- `node qa/visual-check.mjs`：通过，覆盖完整演示链路、1920×1080 无横向溢出、AI 风险分级、急诊插入、小程序同步、叫号与长辈模式。
