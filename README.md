# 影途无忧

医学影像检查智能候诊与全流程引导终端。项目面向 21.5 英寸以上、1920×1080 横屏触摸终端，在原患者端视觉与流程基础上增量加入技师控制端和实时广播能力。

本仓库仅包含终端网页，与“影途无忧”小程序保持为两个独立代码库。

在线演示：<https://eloise126r.github.io/yingtu-wuyou-terminal/>

## 运行

```bash
pnpm install
pnpm dev
```

生产构建与预览：

```bash
pnpm build
pnpm preview
```

## 第二阶段能力

- 公共候检屏仅展示票号、脱敏姓名与状态，不暴露检查项目或敏感病情。
- 五组可切换演示病例，共享签到、准备、安全问卷、体位学习、暂离、急诊插入、叫号与小程序同步状态。
- 覆盖 DR、CT 平扫、CT 增强、MRI 平扫、MRI 增强的结构化准备知识。
- 覆盖 MRI 植入物与 CT 增强风险问卷，命中风险时必须由工作人员二次确认。
- 11 个体位训练课、屏气训练，以及依据 DX/CT/MR 检查指南语料生成的统一标准风格体位插图。
- 60 条影像检查常见问题，按绿/黄/红三级风险输出安全边界。
- 12 秒无操作隐私倒计时、长辈模式、急诊优先与全屏叫号演示。

## 第三阶段增量能力

- 患者首页长按左上角 Logo 3 秒，通过 Demo PIN `1234` 进入 `/technician` 技师工作台；直接访问会返回公共首页。
- 患者端与技师端共享检查室、候检队列、ETA、患者准备状态和广播状态，并通过本地持久化及跨标签页同步完成比赛 Demo 联动。
- 统一消息广播中心与 Web Speech API TTS 队列，支持叫号、急诊优先、安静提醒、设备故障/恢复、检查延迟、自定义通知和准备提醒。
- 技师端支持叫下一位、再次叫号、暂缓/恢复候检、急诊插入、设备状态、暂停/恢复、ETA 人工修正、音量与自动安静提醒。
- 患者端增加温和的全局通知层和检查室实时状态；设备恢复时间未知时只显示“正在评估”，不生成虚假时间。
- 广播历史记录时间、类型、操作人和结果；公共队列仅显示“有安全事项待工作人员确认”，不展示具体敏感信息。

## 可直接演示的路径

- `/` 公共候检首页
- `/scan` 扫码签到
- `/patient` 患者候检总览
- `/preparation` 检查准备知识
- `/safety`、`/mr-safety` 安全筛查
- `/training` 体位与屏气训练
- `/preparation-summary` 准备完成汇总
- `/waiting` 候检、暂离与返回
- `/ai` 影像检查问答
- `/technician` 技师工作台（仅限隐藏入口验证后进入）

## 验证
